# Expense Tracker

A desktop expense tracker built with Python — no external dependencies, just the standard library (Tkinter for the UI, SQLite for storage).

## Features
- Add expenses with date, category, amount, and note
- Filter by month and category
- Delete expenses
- Running total and category-wise breakdown
- Input validation (date format, positive amount)

## Run it
python app/main.py

## Tech
Python, Tkinter, SQLite
